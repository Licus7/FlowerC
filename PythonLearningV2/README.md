# FlowerC 项目计划：制作一款学习 Python 的网站

## 一、初步思路

1. 整体网站结构以上学期的 Think Python 为主，结合人工智能辅助，做一个针对初学者的 Python 学习网站。

2. 先对网页主体同步进行外观设计与内容大纲整理，第二轮加入游戏化互动，增加网站趣味性。

3. 每一章学习后出题（选择题/代码题），代码题答案检测是挑战。答题部分设置分数，不达标强制继续学习，不得进入下一章。

4. 网站包含登录注册功能，支持用户信息保存与学习进度保存。

## 二、教学内容

### 基于《Think Python》的 12 章学习规划

**核心思想**：每章都包含必须动手实践的练习（增加代码检测功能）。

#### 第1章：程序之道（The Way of the Program）
关键词：编程语言、高级语言、低级语言、解释型语言、编译型语言、程序、调试、语法错误、运行时错误、语义错误。
描述：编程世界的导览，介绍编程基本概念、Python 定位及常见错误类型。

#### 第2章：变量、表达式和语句（Variables, Expressions and Statements）
关键词：变量、赋值语句、变量名（标识符）、表达式、语句、值类型、运算符、操作数、求值顺序、注释。
描述：学习程序的基本构建块——用变量存储数据、用表达式计算、编写有效语句。

#### 第3章：函数（Functions）
关键词：函数调用、内置函数、类型转换函数、数学函数、自定义函数、定义、参数、实参、形参、返回值、组合。
描述：介绍如何使用现成函数，并开始学习创建自定义函数来组织和复用代码。

#### 第4章：接口设计（Case Study: Interface Design）
关键词：turtle 模块、接口设计、重构、开发计划、文档字符串。
描述：通过“海龟绘图”案例，学习逐步开发程序，理解良好接口设计的重要性。

#### 第5章：条件和递归（Conditionals and Recursion）
关键词：模运算符、布尔表达式、逻辑运算符、条件语句、if/elif/else、链式条件、嵌套条件、递归。
描述：学习让程序根据条件判断，并初次接触递归这一强大编程思想。

#### 第6章：有返回值的函数（Fruitful Functions）
关键词：返回值、增量开发、组合、布尔函数、栈图、程序框架、守卫。
描述：深入探讨如何编写“有结果”的函数，学习增量开发与栈图调试方法。

#### 第7章：迭代（Iteration）
关键词：while 循环、重新赋值、break 语句、平方根算法（案例）、算法。
描述：学习使用 while 循环迭代，通过计算平方根的经典案例理解算法。

#### 第8章：字符串（Strings）
关键词：字符串序列、len()、遍历 for...in、字符串切片、不可变性、字符串方法、in 运算符、字符串比较。
描述：将字符串作为序列深入学习，掌握各种操作和方法。

#### 第9章：文字游戏（Case Study: Word Play）
关键词：字符串遍历、搜索循环、计数器、字符串方法实战。
描述：经典字符串处理案例，通过分析文本单词巩固字符串与循环知识。

#### 第10章：列表（Lists）
关键词：列表序列、元素、索引、遍历、嵌套列表、列表切片、列表方法、映射、过滤、化简、对象和值、别名。
描述：学习最常用的数据结构——列表，掌握基本操作和高级函数式编程概念。

#### 第11章：字典（Dictionaries）
关键词：字典、键值对、映射、哈希、遍历字典、反向查找、字典作为计数器集合、备忘录、全局变量。
描述：学习另一种核心数据结构——字典，通过键存储和访问值，效率极高、用途广泛。

#### 第12章：元组（Tuples）
关键词：元组、不可变序列、元组赋值、作为返回值、变长参数元组、列表与元组的比较、序列的序列。
描述：学习元组这一不可变序列，理解与列表的区别，掌握元组在赋值、返回多值等场景下的妙用。

## 三、网页功能

**以下为初步设计：**

开始界面包含：

1. **教学部分 Courses**（教学文本或视频及随堂练，可获得大量金币）

2. **答题部分 Pass levels**（通过选择题、填空题、代码题获得不同数量金币）
   - 教学与答题包含同样章节（关卡 level），合并为同一部分

3. **用户系统 User System**（查询存档数据与用户信息，后期可制作成就和好友对战系统）

4. **收集（道具/精灵）系统 Collecting System**（查看金币 coin、精灵球 ball、精灵 Pokemon）
   - 通过精灵陪伴与收集使用户获得动力，后续增加精灵功能

5. **抽奖系统 Catch Pokemon**（金币兑换抽奖次数，精灵球可用等值金币获取，随机遇到宝可梦，过程尽量简略）
   - 金币数量一直显示在右上角

6. **退出**

## 五、项目范围管理计划

### 1. 项目目标与范围

- **项目愿景**：打造集系统性、趣味性于一体的 Python 初学者在线学习平台，通过游戏化机制提升用户学习动力和完成率。
- **主要目标**：完成一个供初学者学习 Python 的网站，实现教学功能和用户系统。
- **功能目标**：完成基于《Think Python》前 6 章的教学内容开发、集成代码编辑与运行环境、实现用户学习进度跟踪与金币奖励系统。
- **质量目标**：系统核心功能测试通过率 100%，主要页面响应时间小于 3 秒。
- **交付目标**：在第 8 周末部署一个可用的最小可行产品（MVP），供内部评审和初步用户测试。
- **范围描述**：开发一个 B/S 架构的 Web 应用，包括前端用户界面、后端业务逻辑与数据库。核心功能为课程学习、习题作答（选择题、填空题、代码题）、用户管理、金币与精灵收集系统。

**可交付成果**：

- 网站源代码
- 项目计划文档
- study guide

### 2. 范围边界与排除

**本项目范围内包含：**

- 12 章完整的教学文本内容
- 基本的文字/图片教学展示
- 选择题、填空题、代码题（基础检测）的作答与自动评分
- 用户注册、登录、个人进度保存
- 金币、精灵球、精灵的获取与展示

**明确排除在本版本之外（后续版本考虑）：**

- 教学视频的制作与集成
- “好友对战系统”等高级社交功能
- 精灵的复杂交互或养成功能

## 九、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 代码题自动检测难度高 | 影响答题模块完整性 | 初期只做基础检测，后续迭代 |
| 多页面路径管理复杂 | 部署后资源 404 | 统一使用相对路径，部署前全面测试 |
| 团队协作版本冲突 | 影响开发进度 | 使用 Git 分支管理，定期合并 |
| 时间紧张 | 功能无法全部完成 | 优先完成 MVP，后续迭代 |
| 浏览器缓存导致旧版本加载 | 调试困难 | 加版本号（`?v=2`）绕过缓存 |
